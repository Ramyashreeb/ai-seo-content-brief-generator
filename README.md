# AI SEO Content Brief Generator

An AI-powered SEO Content Brief Generator that transforms a target keyword and business context into a structured, writer-ready SEO content brief.

The tool helps content teams and writers quickly plan SEO-friendly articles while maintaining clear search intent, audience alignment, content structure, and quality standards.

## Features

- Generate structured SEO content briefs from a primary keyword and business context
- Identify and define search intent
- Define the target audience
- Generate SEO title recommendations
- Generate secondary keyword suggestions
- Recommend an appropriate word count
- Create a detailed H1/H2/H3 content outline
- Generate People-Also-Ask (PAA) questions
- Suggest a unique content angle
- Identify internal linking opportunities
- Generate a recommended CTA
- Provide writer instructions and content constraints
- Built-in Writer QA checklist
- Interactive brief viewing
- Outline-only view
- Raw Markdown output
- Print/export functionality
- Quick scenario presets for different industries

## SEO Quality Rules

The generator is designed to follow practical SEO principles:

- Prioritizes genuine search intent
- Avoids keyword stuffing
- Avoids fabricated search volume, SERP statistics, or ranking claims
- Encourages evergreen content
- Promotes clear and useful content structures
- Encourages neutral and reader-focused CTAs
- Helps explain technical terminology clearly
- Includes quality assurance checks before publishing

## Example Use Case

### Input

**Primary Keyword:**

`best python courses for beginners`

**Business Context:**

An online technology education platform providing programming courses and career-oriented learning resources for beginners and college students.

1. Primary Keyword

6. Secondary Keywords
7. Recommended Word Count
8. Content Outline
9. People-Also-Ask Questions
10. Unique Content Angle
11. Internal Link Opportunities
12. Recommended CTA
13. Writer Instructions
14. Quality Checklist
